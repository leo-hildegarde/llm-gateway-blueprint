# 02 — Spend: make usage visible

Persist usage early. Cost visibility changes how routing decisions are made later.

Once calls are centralized, the gateway can answer questions such as:

- Which model is driving cost?
- Which workloads are unusually expensive?
- Are fallbacks increasing spend?
- Is a cheaper model good enough for routine work?

The public blueprint includes a tiny read-only MCP service to demonstrate the next step: operational data can be queried from clients without giving those clients database credentials.
